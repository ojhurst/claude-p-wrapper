What the logs tell you

  • The exact time of every call, to the second
  • Which script made it, and the chain of programs that started it
  • The machine and folder it ran from
  • The model requested and the first words of the prompt
  • Whether it succeeded

What they leave out

  • Which Claude account paid. Nothing records whether a call ran on your account or Nick's.
  • Tokens or cost. Only prompt length in characters.
  • Which website sent a bridge request. The bridge only names the app in its failure log.
  • Interactive Claude Code sessions in the VS Code and Chrome panels. Those never go through the wrapper.
  • One image path in the bridge that calls Claude directly and skips the wrapper.

Worth a look

  • Upwork scorer: 432 calls on the default model (Opus), each with a prompt of about 136,000 characters. Likely the heaviest single job.
  • Heartbeat: 1,417 "say ok" pings on the default model (Opus) where Haiku would do.
  • Account probes: about 1,000 "Reply with ok" calls from the account switcher.
